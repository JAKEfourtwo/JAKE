## [0.1.0] - 2026-05-14

### Added
- Initial MVP release
- Core ingestion pipeline with LLM extraction
- Knowledge graph (triples) + basic wiki generation
- Query engine with natural language synthesis
- Health & integrity checks (contradiction detection)
- Schema & ontology (`graph/schema.json`)
- GitHub Actions CI workflow
- Professional README and documentation
- Error handling + logging across modules

### Changed
- Improved robustness in PDF/text extraction
- Better error recovery in LLM calls
