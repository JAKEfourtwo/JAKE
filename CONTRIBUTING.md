# Contributing to J.A.K.E

Thank you for your interest in contributing to J.A.K.E!

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes
4. Push to the branch
5. Open a Pull Request

## Development Setup

```bash
git clone https://github.com/JAKEfourtwo/JAKE.git
cd JAKE
pip install -r requirements.txt
```

## Code Style

- Follow PEP 8
- Add logging for important operations
- Handle errors gracefully
- Write clear docstrings

## Areas Where Help is Welcome

- Vector search improvements (sqlite-vec, hybrid retrieval)
- Advanced PDF parsing (layout, tables, images)
- Agent development
- UI (Obsidian plugin, Tauri, web)
- Documentation & examples

## Pull Request Process

- Ensure CI passes
- Update CHANGELOG.md if applicable
- Keep PRs focused

Thank you!
